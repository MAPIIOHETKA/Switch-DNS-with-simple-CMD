

# Switch-DNS-with-simple-CMD

> Простая Windows-утилита в одном `.bat`-файле: автоматически находит активный сетевой адаптер, показывает текущие DNS и позволяет сменить их на один из популярных публичных DNS-серверов в пару нажатий.

## Возможности

- **Автоопределение активного адаптера** — через `Get-NetConnectionProfile` / `Get-NetIPConfiguration`, с ручным вводом имени как fallback.
- **Отображение текущих DNS** — одновременно IPv4 и IPv6 в шапке меню.
- **8 популярных DNS-провайдеров** из коробки:

  | # | Провайдер | Primary | Secondary |
  |---|-----------|---------|-----------|
  | 1 | Google DNS | 8.8.8.8 | 8.8.4.4 |
  | 2 | Cloudflare | 1.1.1.1 | 1.0.0.1 |
  | 3 | Quad9 | 9.9.9.9 | 9.9.9.10 |
  | 4 | OpenDNS | 208.67.222.222 | 208.67.220.220 |
  | 5 | AdGuard DNS | 94.140.14.14 | 94.140.15.15 |
  | 6 | DNS.Watch | 84.200.69.80 | 84.200.70.40 |
  | 7 | CleanBrowsing | 185.228.168.168 | 185.228.169.168 |
  | 8 | Control D | 76.76.2.0 | 76.76.10.0 |

- **Ручной ввод** собственных DNS (IPv4 и IPv6).
- **Сброс на DHCP** — вернуть автоматическое получение DNS одним пунктом меню.
- **Валидация IP-адресов** через `[System.Net.IPAddress]::TryParse` (поддерживает IPv4 и IPv6).
- **Проверка прав администратора** с автоматическим перезапуском через UAC.
- **Сброс DNS-кэша** (`ipconfig /flushdns`) после каждого изменения.
- **Проверка ошибок** `netsh` — если что-то не применилось, скрипт скажет, а не напишет «Готово».

## Требования

- Windows 10 / 11 (на Windows 8/8.1 и 7 тоже должно работать).
- PowerShell 5.0+ (стоит по умолчанию в Win10/11).
- Права администратора (скрипт сам запросит через UAC).

## Использование

1. Запусти `DNS Changer.bat`.
2. В шапке меню увидишь активный адаптер и его текущие DNS.
3. Введи номер нужного DNS-провайдера (1–11) и нажми Enter.

- Пункт **9** — ручной ввод. Принимает IPv4 и IPv6, адреса валидируются.
- Пункт **10** — сбрасывает DNS на автоматическое получение от провайдера (DHCP) как для IPv4, так и для IPv6.
- Пункт **11** — выход.

## Как это работает

Внутри — обычный `cmd.exe` + вызовы `netsh` и PowerShell:

| Задача | Инструмент |
|--------|------------|
| Определение активного адаптера | `Get-NetConnectionProfile` через PowerShell |
| Вывод текущих DNS | `netsh interface ip show dns` |
| Установка статического DNS | `netsh interface ip set dns ... static` |
| Добавление второго DNS | `netsh interface ip add dns ... index=2` |
| Сброс на DHCP | `netsh interface ip set dns ... source=dhcp` |
| Валидация IP | `[System.Net.IPAddress]::TryParse` в PowerShell |
| Сброс кэша | `ipconfig /flushdns` |

Скрипт использует `netsh`, а не `Set-DnsClientServerAddress`, потому что `netsh` одинаково работает на Windows 7/8/10/11, а также умеет одним вызовом переключать DNS на DHCP (`source=dhcp`).

## Известные проблемы и решения

### Окно мигает и сразу закрывается

**Причина:** запуск не от администратора. Скрипт вызывает UAC-перезапуск и завершает текущий процесс — если UAC отклонить, окно закроется.

**Решение:** разрешить UAC-запрос. Если проблема остаётся — запусти `.bat` правой кнопкой → «Запуск от имени администратора».

### Русский текст отображается как «кракозябры»

Скрипт поставляется в **ASCII-версии** (все надписи на английском) — работает при любой кодировке. Это сделано специально, чтобы избежать классической проблемы `cmd.exe` с кодировками.

Если хочешь русский интерфейс — есть две рабочие схемы:

**Вариант А (рекомендуется) — cp866**
1. Убрать из скрипта строку `chcp 65001`.
2. В Notepad++: **Кодировки → Набор символов → Кириллица → OEM 866**.
3. Сохранить.

**Вариант Б — UTF-8 без BOM**
1. Notepad++: **Кодировки → Преобразовать в UTF-8** (именно «Преобразовать»).
2. Убедиться, что выбрано `UTF-8`, а не `UTF-8-BOM`.
3. Оставить `chcp 65001 >nul` в начале скрипта.
4. Сохранить.

> Обычный Блокнот Windows всегда добавляет BOM к UTF-8 — из-за этого первая строка `@echo off` превращается в мусор и скрипт падает. Используй **Notepad++**, **VSCode** или **AkelPad**.

### «Отказано в доступе» при смене DNS

Запущено без прав администратора. Закрой окно, запусти `DNS Changer.bat` от имени администратора.

### После смены DNS ничего не изменилось

Windows кэширует DNS. Скрипт делает `ipconfig /flushdns` автоматически, но некоторые приложения (браузеры) держат свой кэш — перезапусти их. В Chrome: `chrome://net-internals/#dns` → Clear host cache.

## Разработка

Весь проект — один файл `.bat`. Форкни, редактируй, присылай PR.

Особенно приветствуются:

- Поддержка DoH/DoT (это уже за пределами `netsh`, нужен PowerShell `Add-DnsClientDohServerAddress`).
- Сохранение последнего выбранного профиля.
- Цветной вывод через PowerShell `Write-Host`.
- Сохранение/восстановление DNS-настроек в файл.
